Sprint 24A — Dashboard Salary UI Alignment

Objective

The Salary Engine now follows the cumulative milestone model.

The dashboard is still displaying data using the previous salary model.

This sprint is UI/business-logic alignment only.

Do NOT modify any financial engine.

Do NOT modify salary calculations.

Do NOT modify qualification logic.

Only update how the dashboard reads and displays salary information.

----------------------------------------

Issue 1 — Current Rank

The dashboard currently displays a single rank:

Example:

Current Rank: Silver

This is misleading.

Prime Wave uses cumulative salary milestones.

Example:

Master currently owns:

Bronze
Silver

Gold is NOT yet unlocked.

The dashboard must display cumulative achievements instead of implying only one active rank.

Show either:

• Unlocked Salary Ranks:
Bronze
Silver

or

• Highest Milestone:
Silver

PLUS

• Active Salary Benefits:
Bronze + Silver

The UI must clearly indicate that previously unlocked milestones remain active.

----------------------------------------
