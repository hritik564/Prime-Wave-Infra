# Sprint M3A.1 — Network Intelligence Polish & Bug Fix

This sprint is strictly for polishing the existing Network Intelligence page and fixing the remaining issues discovered during QA.

No new features should be added in this sprint.

---

## 1. Fix Binary Tree Layout (Highest Priority)

The React Flow tree is currently broken.

Problems observed:
- Nodes overlap each other.
- Text overlaps between adjacent nodes.
- Child nodes collide.
- Edge routing is inconsistent.
- Layout spacing changes depending on data.
- Initial zoom/FitView does not always produce a clean layout.

Requirements:

- Use an automatic tree layout (Dagre, ELK or equivalent).
- Parent-child spacing must remain consistent regardless of tree size.
- No node should ever overlap another.
- Edges should never cross unnecessarily.
- Automatically fit the entire tree on initial load.
- Smooth zoom and pan.
- Clicking a node should continue opening the Member Drawer.
- Tree must remain readable on desktop, tablet and mobile.

Success Criteria:
- Test with 2 members.
- Test with 20 members.
- Test with 100+ members.
- Layout must remain clean without manual adjustment.

---

## 2. Fix NaN Values

Currently some statistics display:

NaN BV

This should never happen.

Anywhere a value is undefined, null or not yet calculated, display:

0 BV

instead of:

NaN BV

Apply this throughout the entire Network Intelligence page.

## 3. Improve Weak Leg Status

Replace the current generic status with meaningful labels.

Examples:

If both legs are equal:
"Perfectly Balanced"

If left leg is weaker:
"Weak Leg: LEFT"

If right leg is weaker:
"Weak Leg: RIGHT"

If the user has not yet qualified:
"Not Qualified Yet"

The status should always clearly communicate the user's network health.
