# Sprint 23A — Deposit Center (Admin Panel)

Objective

Build a dedicated Deposit Center for the Prime Wave Admin Panel.

This module will become the operational center for all user deposits.

IMPORTANT

Do NOT redesign the Admin Panel.

Follow the same design language used by:

• Withdrawal Center

• Investment Center

• Wallet Control Center

The Deposit Center should feel like a native part of the existing Admin Panel.

--------------------------------------------------------
Business Rules (LOCKED)
--------------------------------------------------------

A user deposit follows this lifecycle:

Deposit Created

↓

Pending

↓

Finance Review

↓

Approved

↓

Deposit Wallet Credited

↓

Ledger Entry Created

↓

Audit Log Created

↓

User Notification

The Deposit Center must support BOTH:

• Manual approval (current)

• Automatic approval via payment gateway/webhook (future)

The UI should already support both workflows.

--------------------------------------------------------
Admin Actions
--------------------------------------------------------

Support:

Approve Deposit

Reject Deposit

Mark as Confirming

View Blockchain Transaction

Approve:

Credits Deposit Wallet automatically.

Reject:

Requires rejection reason.

Mark as Confirming:

Updates status only.

--------------------------------------------------------
Approval Behaviour
--------------------------------------------------------

When a deposit is approved:

Automatically:

• Credit Deposit Wallet

• Create Wallet Ledger Entry

• Create Audit Log

• Create Notification

• Update Deposit Status

No manual wallet credit should be required.

--------------------------------------------------------
Manual Wallet Credits
--------------------------------------------------------

Do NOT remove the existing Manual Wallet Credit tool.

However:

Normal deposits should flow ONLY through the Deposit Center.

Manual Wallet Credit remains an emergency administrative tool.

--------------------------------------------------------
Goal
--------------------------------------------------------

Create a production-ready Deposit Center that completes Prime Wave's financial lifecycle by providing a dedicated operational module for reviewing, approving, tracking and auditing user deposits while remaining fully compatible with future automated crypto payment processing.
