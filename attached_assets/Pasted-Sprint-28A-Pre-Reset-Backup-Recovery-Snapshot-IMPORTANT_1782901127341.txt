Sprint 28A — Pre-Reset Backup & Recovery Snapshot

IMPORTANT

DO NOT DELETE ANY DATA.
DO NOT MODIFY ANY DATA.
DO NOT RUN ANY MIGRATIONS.
DO NOT TOUCH THE DATABASE CONTENTS.

This sprint is BACKUP ONLY.

We are preparing for a complete production reset, but before deleting anything I want a verified recovery point.

Objectives

========================
PART 1 — Production Database Backup
========================

Create a full production PostgreSQL backup.

Requirements:

- Complete database dump
- Schema
- Data
- Indexes
- Constraints
- Sequences
- Triggers
- Prisma migration history

Verify the dump completed successfully.

Report:

- Backup filename
- Backup size
- Timestamp
- Success/failure

========================
PART 2 — Environment Audit
========================

Generate a report of the production environment.

Include:

- Current deployed commit/build
- Prisma version
- Node version
- PostgreSQL version
- Current migration version
- Applied migrations
- Active environment
- RPC configuration status
- Company wallet configuration
- System settings count

DO NOT expose secrets.

Only confirm they exist.

Example:

BSC_RPC_PRIMARY
✓ Present

DATABASE_URL
✓ Present
