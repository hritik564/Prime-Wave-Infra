# Sprint 33B – Integrate Power BV into Binary Matching & Binary Orbit

Sprint 33A has been approved.

We will now integrate Power BV into ONLY the Binary Matching and Binary Orbit engines.

DO NOT modify:

- Salary Qualification
- Salary Scheduler
- Level Income
- BV Propagation
- Investments
- Wallet Transactions (except metadata additions)
- Existing BV Ledger structure

Salary will be redesigned in Sprint 33C.

--------------------------------------------------
OBJECTIVE
--------------------------------------------------

Power BV must now participate in:

✅ Binary Matching

✅ Binary Orbit

Power BV must still NEVER:

- Propagate upward
- Create investment records
- Create sponsor business
- Create level income
- Affect salary (yet)

--------------------------------------------------
BINARY MATCHING
--------------------------------------------------

Candidate query must include members having:

Organic Left BV > 0
OR
Power Left BV > 0

AND

Organic Right BV > 0
OR
Power Right BV > 0

Working calculation:

Effective Left BV

=

Organic Left BV

+

Power Left BV

Effective Right BV

=

Organic Right BV

+

Power Right BV

Matched BV

=

MIN(Effective Left, Effective Right)

--------------------------------------------------
FLUSH RULE
--------------------------------------------------

Consume Organic BV first.

If Organic BV is exhausted,
consume Power BV.

Example:

Organic Left

100

Power Left

50

Matched

120

Result:

Organic Left

0

Power Left

30

Never consume Power BV before Organic BV.

--------------------------------------------------
BINARY ORBIT
--------------------------------------------------

Apply exactly the same logic.

Candidate selection:

Organic + Power.

Reward calculation:

Organic + Power.

Flush:

Organic first.

Power second.
