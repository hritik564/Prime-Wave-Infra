# Sprint QA-2 — Prime Wave Developer Testing Toolkit

## Objective

Build a secure Developer Testing Toolkit that allows the development team to execute production business logic instantly without waiting for scheduled jobs.

This toolkit is for testing only.

It must NEVER be available in production.

---

# SECURITY

The toolkit must only be enabled when:

NODE_ENV === "development"

If NODE_ENV === "production":

* The page must not exist.
* Routes must not exist.
* APIs must not exist.
* Buttons must not exist.

This is mandatory.

---

# Developer Page

Create:

/dev-tools

Display a warning banner:

"Developer Testing Toolkit — Disabled in Production"

---

# SECTION 1 — ROI Engine

Buttons:

• Run Next ROI Cycle

Runs the exact production ROI scheduler once.

Do NOT duplicate ROI logic.

Call the existing scheduler/service.

---

• Run 1 Day ROI

Runs two ROI cycles.

---

• Run 7 Day ROI

Runs fourteen ROI cycles.

---

• Run 30 Day ROI

Runs sixty ROI cycles.

---

Display after execution:

* Investments Updated
* ROI Generated
* Auto Compounded Amount
* Claimable ROI Generated
* Execution Time

---

# SECTION 2 — Investment Controls

Allow selecting any investment.

Actions:

• Mark Investment Matured

This should execute the same maturity logic used by production.

Expected result:

* Principal becomes claimable.
* Investment status updates.
* Dashboard refreshes.

---

• Reset Investment

Development only.

Returns selected investment to Active status.

Never modify business rules.

Never duplicate calculations.

Every button must execute the existing production services.
