Business Rules (LOCKED)

1. Investment Plans

New plans may be created.

Existing plans that already have active investors become financially immutable.

The following values cannot be modified once members have invested:

• Investment Amount

• BV

• ROI

• Duration

If new terms are required, create a new plan version.

---

2. Compensation Rules

Changes to:

• Binary Matching

• Level Income

• Salary Income

• Binary Orbit

apply only to future calculations.

Historical payouts must never be recalculated.

---

3. Transfer Rules

72-hour transfer configuration affects only future transfers.

Existing transfer schedules must continue using the rules that were active when the transfer started.

---

4. Version History

Every configuration change creates a new configuration version.

No configuration history may be overwritten.
