# Sprint 33I – Salary Approval & Payout Engine

Sprint 33H has been approved.

This sprint implements the Salary Approval & Payout Engine.

The monthly salary generation engine is complete.

SalaryIncome records are now immutable monthly snapshots.

This sprint is responsible ONLY for approving those records and crediting member wallets.

⚠️ IMPORTANT

This sprint DOES NOT change:

- Qualification
- Salary generation
- Monthly snapshot rules
- SalaryBusinessSummary
- SalaryAchievement
- SalaryBusinessEvent

Those systems are complete.

--------------------------------------------------
OBJECTIVE
--------------------------------------------------

Implement the Salary Approval & Payout Engine.

The engine must:

• Approve pending salaries

• Credit Withdrawal Wallet

• Record immutable payout history

• Prevent duplicate payouts

• Support batch processing

• Be fully transactional

--------------------------------------------------
PAYOUT MODEL
--------------------------------------------------

Salary lifecycle is:

PENDING

↓

APPROVED

↓

PAID

These transitions are one-way only.

Never allow:

PAID

↓

APPROVED

or

APPROVED

↓

PENDING

Historical salary records must never be edited backwards.

--------------------------------------------------
PAYOUT
--------------------------------------------------

Implement:

paySalary(incomeId)

Rules:

Status must equal:

APPROVED

Open one Prisma transaction.

Inside transaction:

1.

Lock SalaryIncome row.

2.

Verify status still APPROVED.

3.

Credit:

Withdrawal Wallet

(amount = salaryAmount)

4.

Create WalletTransaction.

Category:

SALARY

Reference:

SalaryIncome.id

5.

Update SalaryIncome

status

↓

PAID

paidAt

transactionId

Commit.

--------------------------------------------------
ATOMICITY
--------------------------------------------------

Wallet credit

+

WalletTransaction

+

SalaryIncome update

must succeed together.

If any fails:

Rollback everything.

--------------------------------------------------
IDEMPOTENCY
--------------------------------------------------

Calling:

paySalary()

twice

must

NOT

credit wallet twice.

If already PAID:

Return duplicate.

No updates.

No wallet credit.
