Sprint 20D — Investment Center Backend Integration

Objective

Replace all mock investment data and local interactions with live backend integration while preserving the existing UI exactly as it is.

IMPORTANT

Do NOT redesign the Investment Center.

Do NOT modify layouts, styling, routing or components.

Only replace mock data and local actions with backend operations.

## Business Rule (Locked)

Investments NEVER require admin approval.

Once a user successfully invests, the investment is automatically:

* Recorded in the database
* Marked as Active
* Linked to the user's account
* Added to the ROI engine
* Added to Binary BV calculations
* Added to Audit History

The Investment Center is for monitoring, auditing and managing investments—not approving them.

Platform Rules

Investments are financial records.

Once Active:

✓ View

✓ Audit

✓ Notes

✓ Freeze (if supported)

✓ View ROI Schedule

✓ View Wallet Movement

✗ Cannot edit Amount

✗ Cannot edit Plan

✗ Cannot edit ROI

✗ Cannot edit Duration

If an admin attempts to edit locked financial values, display:

"This investment is an active financial record and cannot be modified."
