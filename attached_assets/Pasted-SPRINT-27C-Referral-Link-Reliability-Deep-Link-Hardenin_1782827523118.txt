SPRINT 27C — Referral Link Reliability & Deep Link Hardening

OBJECTIVE

Fix the referral link system so that every shared referral link automatically pre-populates the sponsor and placement information correctly across desktop and mobile devices.

This sprint is ONLY about referral onboarding reliability.

Do NOT modify:

- Registration business logic
- Binary placement logic
- Wallet engine
- Deposit engine
- Financial calculations
- Income engines

Only fix the referral/deep-link flow.
