# Sprint 33P – Production Database Migration & Schema Synchronization

This sprint is NOT a feature sprint.

Do NOT modify business logic.

Do NOT refactor existing services.

Do NOT change compensation calculations.

Do NOT alter qualification rules.

The objective is to bring the production database into complete alignment with the current application schema developed during Sprints 33E–33W.

--------------------------------------------------
OBJECTIVE
--------------------------------------------------

Synchronize the production database with the canonical Prisma schema.

Preserve all existing production data.

Generate proper Prisma migrations for every schema change that was previously applied only through development db push operations.

After completion, production and schema.prisma must be 100% identical.
