==================================================
1. MOST IMPORTANT RULE — DO NOT BREAK AUTH
==================================================

This is primarily a FRONTEND/UI redesign.

Before making changes:
- Inspect the existing authentication implementation.
- Understand the current login, signup, forgot-password, validation, session, API, and routing logic.
- Preserve all existing functionality.

DO NOT:
- change authentication APIs
- change backend logic
- change database logic
- change routes
- remove validation
- remove error handling
- remove loading states
- change session behavior
- replace working authentication with mock authentication
- create a fake/demo login
- store credentials insecurely
- introduce unnecessary dependencies

The current authentication implementation is the SOURCE OF TRUTH for functionality.

The attached image is the SOURCE OF TRUTH for visual direction.

==================================================
4. BACKGROUND — KEEP IT SIMPLE
==================================================

This is one of the most important requirements.

DO NOT create a busy animated background.

Use a nearly-black / deep charcoal background.

Add only a few subtle visual elements:

- extremely faint grid lines
- one or two very large, extremely subtle orbital curves
- a very soft cyan ambient glow
- a few tiny nodes/points
- extremely subtle AI/network geometry

The background should be almost invisible at first glance.

The user should notice the atmosphere before they notice the graphics.

Do NOT use:
- giant particle fields
- hundreds of floating particles
- complicated circuit boards
- huge glowing AI brains
- excessive network lines
- rainbow gradients
- purple neon
- excessive 3D
- busy animated backgrounds

The reference image demonstrates the desired balance.

The background should say:

"AI-powered infrastructure"

without literally showing an AI brain.

==================================================
5. SUBTLE AI VISUAL LANGUAGE
==================================================

Introduce AI through very restrained visual cues.

For example:

A small number of connected nodes with a central point.

Or:

A subtle orbital/data visualization behind the login card.

Or:

A faint flowing data path.

The visual should suggest:

intelligence → computation → network → decentralized infrastructure

without becoming a decorative illustration.

Use slow, barely noticeable animation if appropriate.

For example:
- a tiny node slowly pulses
- a subtle line moves along an orbital path
- a faint glow slowly changes intensity

Animations should be extremely slow and elegant.

If removing animation makes the page look cleaner, prefer removing it.

16. MOBILE DESIGN
==================================================

Mobile is extremely important.

The authentication page must be fully responsive.

On mobile:

- PrimeWave logo near the top
- authentication card fits comfortably within viewport
- appropriate horizontal padding
- no horizontal scrolling
- no overlapping decorative elements
- reduce or remove most background decoration
- keep only very subtle AI visual cues
- inputs must be touch-friendly
- button must be easy to tap
- maintain excellent typography and spacing

On small screens, PRIORITIZE USABILITY OVER DECORATION.
