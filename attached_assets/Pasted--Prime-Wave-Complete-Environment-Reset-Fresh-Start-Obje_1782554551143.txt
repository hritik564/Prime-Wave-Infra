# Prime Wave — Complete Environment Reset & Fresh Start

Objective

Prepare Prime Wave for complete end-to-end testing from a clean state.

This is a PRE-LAUNCH RESET.

There are NO real users.

There are NO real funds.

There is NO production history that must be preserved.

The goal is to make both the Development and Production environments start from the exact same clean baseline.

IMPORTANT

Before making ANY changes:

1. Verify both Development and Production databases.

2. Create a full backup/export (or snapshot if supported) of BOTH databases.

3. Confirm the backup completed successfully.

Only then begin the reset.
