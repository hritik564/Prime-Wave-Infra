# Sprint 20J — Production Polish, Consistency & Admin UX Finalization

This is the final Admin Panel sprint.

DO NOT add new platform features.

DO NOT change business logic.

DO NOT modify API contracts.

DO NOT change database schema.

The goal is to make the entire admin panel production-ready, visually consistent, and enterprise-grade.

--------------------------------------------------------
1. Standardize every page
--------------------------------------------------------

Ensure every admin page follows the exact same layout.

Each page must contain:

• Title
• Subtitle
• Consistent spacing
• Top action buttons
• Loading state
• Empty state
• Error state
• Success toast positioning
• Responsive behavior

No page should feel different from another.

--------------------------------------------------------
2. Standardize all tables
--------------------------------------------------------

Every table in the admin panel should use the same component.

Include:

• Sticky header
• Zebra hover
• Consistent spacing
• Pagination
• Page size selector
• Sorting
• Search
• Filter support
• Mobile responsive layout

Pages include:

Members

Investments

Withdrawals

Wallets

Reports

Support

Plans

Everything should feel identical.

--------------------------------------------------------
3. Standardize all status badges
--------------------------------------------------------

Use one Badge component.

ACTIVE

PENDING

Yellow

REJECTED

Gray

Never use different colors for the same status.
