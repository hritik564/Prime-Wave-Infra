# Milestone 3B — Decision Engine

## Objective

Transform the Network Intelligence page into a Decision Engine.

The page should no longer only display information.

It should proactively guide users toward the highest-impact actions they can take today.

The goal is simple:

Every user should leave this page knowing exactly:

• What deserves attention
• Why it matters
• What reward it could unlock
• What action they should take next

This is NOT a chatbot.

This is a decision support system driven entirely by production data.

Reuse existing APIs.

Reuse existing calculations.

Never fabricate recommendations.

No placeholder data.
