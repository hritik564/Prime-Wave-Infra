SPRINT 28J — LEVEL INCOME BUSINESS RULE REFACTOR

IMPORTANT

This sprint changes ONLY the Level Income eligibility rule.

The Binary, Orbit, Salary, Matching, ROI, Deposit, Wallet and Referral engines must remain completely unchanged.

==========================================================
OBJECTIVE
==========================================================

Level Income becomes a PURE REFERRAL COMMISSION.

Binary qualification must NEVER affect Level Income.

The business rule is now:

1. A referred user makes a qualifying investment.

2. Walk up the sponsor chain.

3. Pay every sponsor for the first FIVE levels.

4. Each level receives 1%.

5. No additional eligibility conditions.

==========================================================
NEW BUSINESS RULE
==========================================================

A sponsor receives Level Income if:

✓ They are in the referral chain.

✓ The investment qualifies.

✓ They are within the first five referral levels.

NOT required:

❌ Binary qualification

❌ Left referral

❌ Right referral

❌ Active investment

❌ Minimum BV

❌ Rank

❌ User ACTIVE status

❌ KYC

❌ Binary balance

Level Income and Binary Income are now completely independent systems.

==========================================================
IMPLEMENTATION
==========================================================

Remove the qualification gate from:

artifacts/api-server/src/levelIncome/level-income.service.ts

Current code:

const ancestorActive = await isMemberActive(ancestorId, tx);

if (!ancestorActive) {
    currentUserId = ancestorId;
    continue;
}

Remove this gate completely.

Every ancestor within five referral levels should receive Level Income.

==========================================================
CODE CLEANUP
==========================================================

The helper currently named:

isMemberActive()

does NOT determine whether a member is active.

It determines Binary qualification.

Rename it to something accurate.

Suggested:

isBinaryQualified()

or

hasBinaryQualification()

Update every reference.

This is a refactor only.

Behaviour must remain identical everywhere except Level Income.
