Problems Encountered
Hardhat telemetry prompt in non-TTY — Hardhat's first-run telemetry consent prompt crashes readline when there's no interactive terminal. Fixed by pre-writing {"consent":true} to $PROJECT/.config/hardhat-nodejs/telemetry-consent.json. Documented in memory.
autoInstallPeers: false in workspace — All @nomicfoundation/hardhat-toolbox peer deps had to be declared explicitly in contracts/package.json. Working correctly.
keccak/secp256k1 native builds — Required adding both to onlyBuiltDependencies in pnpm-workspace.yaml.
contracts/tsconfig.json must not extend tsconfig.base.json — The base config uses ESNext/bundler module resolution which conflicts with Hardhat's CommonJS requirement. Standalone tsconfig used.
Design subagent first attempt failed — Re-launched with a more precise brief; second run succeeded.
