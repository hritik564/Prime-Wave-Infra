# Sprint 33F – Salary Qualification Engine

Sprint 33E has been approved.

This sprint implements the Salary Qualification Engine.

⚠️ IMPORTANT

This sprint DOES NOT implement:

- Salary payouts
- Salary scheduler
- Monthly salary generation
- Member UI
- Admin UI
- Cron jobs

This sprint only determines whether a member qualifies for salary ranks and creates SalaryAchievement records.

--------------------------------------------------
OBJECTIVE
--------------------------------------------------

Build the complete Salary Qualification Engine using the new SalaryBusinessSummary model.

The engine must:

• Read salary business counters

• Evaluate qualification rules

• Create SalaryAchievement records

• Never duplicate achievements

• Never revoke achievements

• Never pay salary

Qualification only.

--------------------------------------------------
NEW SERVICE
--------------------------------------------------

Create:

src/salary/salary-qualification.service.ts

Primary responsibilities:

• Determine unlock state

• Calculate effective business

• Evaluate every rank

• Create SalaryAchievement

• Never revoke existing achievements

--------------------------------------------------
UNLOCK STATE
--------------------------------------------------

Unlock MUST NOT be stored.

Determine unlock state by checking:

SalaryAchievement

WHERE

rankName = "Gold"

If a Gold achievement exists:

Unlocked = TRUE

Otherwise:

Unlocked = FALSE

No User flag.

No duplicate state.

--------------------------------------------------

--------------------------------------------------

SalaryBusinessSummary

directBusiness

downlineBusiness

powerBusiness

Rules:

DIRECT_ONLY

Effective Business

=

directBusiness

ALL_BUSINESS

If unlocked:

Effective Business

=

directBusiness

+

downlineBusiness

+

powerBusiness

Otherwise:

Effective Business

=

directBusiness

--------------------------------------------------
QUALIFICATION ENGINE
--------------------------------------------------

Load all active SalaryRankConfig records ordered by requiredBusiness ascending.

For each rank:

Determine:

Effective Business

Compare against:

requiredBusiness

If qualified:

Create SalaryAchievement

ONLY IF

one does not already exist.

Never overwrite existing achievements.

NEVER REVOKE
--------------------------------------------------
