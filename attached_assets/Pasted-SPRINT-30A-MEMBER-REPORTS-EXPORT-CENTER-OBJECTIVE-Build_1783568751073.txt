==========================================================
PERFORMANCE
==========================================================

Do NOT load every member into memory.

Filtering must happen in the database.

Pagination must happen in SQL/Prisma.

Export should stream results if possible.

==========================================================
API
==========================================================

Create reusable reporting endpoints.

GET

/api/admin/reports/members

Supports all filters.

GET

/api/admin/reports/members/export

Returns Excel.

GET

/api/admin/reports/members/export-csv

Returns CSV.

Use ONE shared query builder.

Do NOT duplicate filter logic.
