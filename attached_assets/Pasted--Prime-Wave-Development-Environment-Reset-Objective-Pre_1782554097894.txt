# Prime Wave — Development Environment Reset

Objective

Prepare the development environment for a complete end-to-end platform test.

IMPORTANT

This reset applies ONLY to the DEVELOPMENT environment.

Do NOT affect production (if any).

Do NOT delete source code.

Do NOT modify business rules.

Do NOT remove configuration.

Do NOT remove admin roles or permissions.

--------------------------------------------------------
Delete Development Data
--------------------------------------------------------

Remove all development/test data including:

• Users
• Investments
• Wallet balances
• Deposit history
• Withdrawal requests
• ROI history
• Binary income
• Level income
• Salary income
• Orbit income
• Matching history
• Carry Forward
• Wallet transfers
• 72-hour transfer queue
• Notifications
• Audit entries generated by test users
• Referral relationships
• Binary tree placements
• Reports generated from test data
• Support tickets (if test data)
• Activity history
• Session data
• Cached user data

--------------------------------------------------------
Preserve
--------------------------------------------------------

Keep:

• Source code
• Database schema
• Migrations
• Admin permissions
• Configuration
• Investment plans
• ROI settings
• Binary settings
• Wallet rules
• Platform limits
• Global configuration
• Salary configuration
• Level configuration
• Version history
• System settings

--------------------------------------------------------
Master Account
--------------------------------------------------------

After the reset, automatically create ONE master account.

Requirements:

Username:
master

Display Name:
Master ID

Role:
Super Admin

This account will become the root account used for all future testing.

It must have:

• No sponsor
• No upline
• No binary parent
• Root of the binary tree

The account should be eligible to receive future Left and Right referrals.

Return the Prime Wave development environment to a clean initial state with one root Master ID so complete end-to-end testing can begin from scratch.
