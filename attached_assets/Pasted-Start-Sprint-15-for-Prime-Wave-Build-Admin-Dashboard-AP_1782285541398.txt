========================================
USER STATUS CONTROLS
========================================

Create:

POST /api/admin/users/:id/block

POST /api/admin/users/:id/suspend

POST /api/admin/users/:id/activate

Rules:

BLOCKED:
Cannot login.

SUSPENDED:
Can login but cannot perform business actions.

ACTIVE:
Normal access.

All actions must create AdminLog entries.

========================================
MANUAL WALLET ADJUSTMENTS
========================================

Create:

POST /api/admin/wallet-adjustments

Request:

{
  userId,
  walletType,
  amount,
  reason
}

walletType:

DEPOSIT
INCOME
WITHDRAWAL

Require reason.

Use Prisma transactions.

Create WalletTransaction entry.

Create AdminLog entry.
