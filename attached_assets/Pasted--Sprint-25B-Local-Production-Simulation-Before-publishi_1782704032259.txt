# Sprint 25B — Local Production Simulation

Before publishing, I want one complete end-to-end LOCAL simulation of the automatic deposit pipeline.

Do NOT use the MockBlockchainAdapter.

Instead, keep the real BSCBlockchainAdapter active and mock ONLY the JSON-RPC responses coming from the blockchain.

The objective is to exercise the exact production code path while avoiding a real blockchain transaction.

---

## Requirements

Run one complete deposit verification using:

* Amount: 100 USDT
* Network: BEP20
* Status: Successful
* Confirmations: 12
* Valid recipient
* Valid USDT contract

Everything else must be real.

The following components must execute exactly as they would in production:

* Deposit Verification Engine
* Worker
* Repository
* State Machine
* Optimistic Locking
* Crash Recovery
* approveDeposit()
* Wallet credit
* Ledger creation
* Notifications
* Audit logging
* Event publishing

Do not bypass any business logic.

Do not manually update database rows.

Do not insert records with SQL.

The only mocked component should be the outbound JSON-RPC responses.
