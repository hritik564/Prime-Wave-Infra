- [Prisma migration in Replit](prisma-migrations.md) — `migrate dev` always fails (non-interactive); use resolve+deploy pattern instead
- [Express 5 read-only req.query](express5-readonly-query.md) — `req.query` and `req.params` are getter-only in Express 5; validate middleware stores parsed data in `res.locals`, controllers use `getParsed(res, "query")`.
- [Trust proxy for rate limiter](trust-proxy.md) — Replit reverse proxy sets X-Forwarded-For; must set `app.set("trust proxy", 1)` or express-rate-limit throws ERR_ERL_UNEXPECTED_X_FORWARDED_FOR.
- [Auth rate limiter in tests](auth-rate-limit-tests.md) — authLimiter is 10 req/15 min in-memory; repeated login calls in test scripts exhaust it fast; restart workflow to reset, or use one token per user across all assertions.
- [Prisma JSON metadata typing](prisma-json-metadata.md) — notification/metadata fields typed `Prisma.InputJsonValue`; service callers pass plain object literals which TypeScript checks structurally; do NOT type service input as `Record<string, unknown>` — not assignable to Prisma JSON input types.
- [Level income return for notifications](level-income-notifications.md) — `processLevelIncome` returns `LevelIncomeTarget[]` instead of void; createInvestment destructures `{investment, levelIncomeTargets}` from tx and fires per-ancestor notifications outside the transaction.
- [Framer Motion inside ReactFlow nodes](framer-motion-reactflow-nodes.md) — Never use motion.* components as ReactFlow custom node components; causes non-Error unhandled Promise rejections and crashes.
- [ResizeObserver false crash in Replit](resize-observer-replit.md) — React Flow ResizeObserver triggers a Chrome non-Error window.onerror that Replit's monitoring misreads as a crash; suppress with capture-phase addEventListener + window.onerror override in main.tsx.
- [Admin controllers use req.user not res.locals.auth](admin-auth-access.md) — Admin controllers must read identity from `req.user.sub` / `req.user.email` (AuthenticatedRequest), NOT `res.locals.auth` which is never set in this codebase.
- [Dev vs prod use separate databases](dev-prod-separate-dbs.md) — DATABASE_URL is one secret but Replit injects different connection strings; executeSql environment:"production" is READ-ONLY replica; only way to write prod data is through the deployed API or Publish flow.
- [HTTP_STATUS enum](http-status-enum.md) — SERVICE_UNAVAILABLE (503) was added in Sprint 27B; always extend constants.ts when adding new HTTP codes rather than using raw numbers.
- [VERIFICATION_DELAYED slow-poll pattern](verification-delayed-pattern.md) — Non-terminal timeout state; ACTIVE_VS must include it; keepStatus pattern preserves status on adapter retry/not-found; delayedPollMs from system_settings.
- [Re-validate age clock must use firstSeenAt](revalidate-age-clock.md) — Delay threshold uses firstSeenAt (reset on re-validate), NOT createdAt (never reset). Using createdAt causes re-validate to always immediately enter VERIFICATION_DELAYED for old records.
- [32-bit setTimeout overflow in salary cron](salary-cron-overflow.md) — Any month delay (≥25 days) overflows Node's 32-bit setTimeout → fires at 1ms → infinite loop floods DB pool. Fix: cap all delays at MAX_SAFE_DELAY (12h) and guard with (year, month) pair before running.
- [Admin write normalization](admin-write-normalization.md) — admin edit endpoints must trim/lowercase username & email identically to registration, or login lookup silently mismatches → permanent lockout.
